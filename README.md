# 🧠 PsiFacil Blog

O **PsiFacil Blog** é uma plataforma web full stack desenvolvida para compartilhamento de conteúdos sobre psicologia, bem-estar emocional e desenvolvimento pessoal.

O projeto foi criado com foco em experiência do usuário, design moderno e arquitetura escalável, permitindo a publicação de artigos, interação dos leitores e gerenciamento completo do conteúdo através de um painel administrativo.

# ✨ Funcionalidades

## 👨‍💻 Área Administrativa
- Criação de posts
- Edição de artigos
- Exclusão de conteúdos
- Painel administrativo
- Login autenticado com JWT

## 📚 Blog Público
- Listagem de artigos
- Página individual de posts
- Sistema de curtidas
- Sistema de comentários
- Layout responsivo

## 📩 Sistema de Leads
- Captura de nome e e-mail
- Armazenamento no banco de dados
- Preparado para integração com e-mail marketing

# ⚙️ Como Executar o Projeto

## 1. Clone o repositório

```bash
git clone https://github.com/GustavoLanjoni/Blog---PsiFacil.git
```

## 2. Acesse a pasta do projeto

```bash
cd Blog---PsiFacil
```

## 3. Instale as dependências

```bash
npm install
```

## 4. Configure o arquivo `.env`

```env
DATABASE_URL=sua_url_supabase
JWT_SECRET=sua_chave_jwt
PORT=3000
```

## 5. Inicie o servidor

```bash
node server.js
```
